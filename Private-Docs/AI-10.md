# AI-10 — Phase 4 Complete (Mail Driver Framework)

> Status: **complete** (v0.0.5)  
> Product: **msgate**

---

## Summary

Outbound mail is now behind a pluggable **MailDriver** layer. Legacy Exchange (EWS) is unchanged in behavior — it is driver #1. Graph and Gmail are registered stubs for Phase 4b / 4c.

---

## User guide

### Active backend

Config field `backend` selects the driver:

| Value | Status |
| --- | --- |
| `ews` | **Production** — on-prem Exchange |
| `graph` | Stub — Phase 4b |
| `gmail` | Stub — Phase 4c |

UI header shows **EWS: Connected/Down** (or the active backend label).

### Health checks

| Endpoint | Purpose |
| --- | --- |
| `GET /readyz` | SMTP + active backend health |
| `GET /api/v1/tools/backend-health` | Driver health detail |
| `POST /api/v1/tools/ews-health` | Legacy EWS-only check |

### Web login (unchanged)

Operator auth is Phase 3.5 — setup wizard, session login, root reset. See `AI-08.md` / `AI-01.md` §6b.

## Adding a new provider (developer)

1. Implement `MailDriver` in `drivers/<name>.py`
2. Register in `drivers/registry.py`
3. Add config model + `backend` enum value if needed
4. No queue/UI rewrite required
