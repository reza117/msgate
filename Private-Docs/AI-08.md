## User guide — login process

### First install (normal path)

1. Start: `msgate serve`
2. Terminal banner: *Open http://127.0.0.1:8080/ to set your password*
3. Browser → **Create administrator password** (`/ui/setup`)
4. Username is fixed: `admin`
5. After setup → dashboard (logged in)

### Later visits

1. Open `http://127.0.0.1:8080/ui/login` (or `/` → redirect)
2. Sign in as `admin` with your password
3. Session cookie keeps you signed in

### Sign out

Sidebar **Sign out** → clears session → login page.

### Temporary / bootstrap password

| How you got it | What happens |
| --- | --- |
| `MSGATE_ADMIN_PASSWORD` env (Docker/CI) | First login → **must** change password |
| `sudo msgate admin reset-password` | Next login → **must** change password |

While temporary: **red warning bar** at top of UI until a new password is saved.

### Lost password (server admin)

```bash
sudo msgate admin reset-password
```

- Requires Linux **root** (uid 0)
- Non-root exits with error
- Sets new password + `must_change_password`

### Help

- Sidebar **Help ↗** → GitHub Pages (`MSGATE_HELP_URL`)
- In-app stub: `/ui/help`

## What stays public (no login)

| Path | Why |
| --- | --- |
| `/healthz` | Zabbix / K8s liveness |
| `/readyz` | Readiness probes |
| `/ui/setup` | Only when no admin exists yet |

Everything else under `/`, `/ui/*`, `/api/v1/*` requires a valid session.
