## Summary

Web UI and API are now password-protected. First install uses a browser setup wizard — no hardcoded default password.

---

## User guide

### First install

1. Start msgate: `msgate serve`
2. Terminal shows: *Open http://127.0.0.1:8080/ to set your password*
3. Browser opens setup page → choose admin password → dashboard

### Sign in

- URL: `http://127.0.0.1:8080/ui/login`
- Username: `admin`

### Reset password (server admin)

```bash
sudo msgate admin reset-password
```

Requires Linux root. Next login forces a new password.

### Docker / automation

```bash
export MSGATE_ADMIN_PASSWORD="temporary-secret"
```

First login redirects to change-password screen. Red bar until updated.

### Help

- Sidebar **Help ↗** → GitHub Pages (`MSGATE_HELP_URL`)
- In-app stub: `/ui/help`
