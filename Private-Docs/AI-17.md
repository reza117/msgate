## Summary

A concurrent SMTP burst harness (`scripts/load_test_smtp.py`) plus an in-process pytest smoke (`tests/test_load_burst.py`). Public docs list starting capacity targets and pass criteria.

---

## User guide

```bash
python3 scripts/load_test_smtp.py --host 127.0.0.1 --port 25 --count 500 --concurrency 25
```

See GitHub Pages: `docs/capacity-loadtest.md`.

## Documented starting targets

| Metric | Target |
| --- | --- |
| Burst SMTP accept | ≥ 100 msg/s enqueue (localhost) |
| Default pending cap | 5000 → SMTP 452 |
| Workers | 2 (env tunable) |

Measure on your host; adjust `MSGATE_QUEUE_*` / Postgres as needed.
