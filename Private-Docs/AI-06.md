## GitHub Pages — User manual

### Open the UI

```bash
msgate serve
# Browser: http://127.0.0.1:8080/
```

### Pages

1. **Overview** — sent today, latency, auth errors, queue depth; live SMTP/EWS events  
2. **Messages** — click **Inspect** for MIME preview, auth fields, errors  
3. **Tools** — send test mail, paste AUTH PLAIN base64, run Exchange health check  

### Auth simulator example

Paste base64 from Zabbix `AUTH PLAIN` into Tools → Auth Simulator.  
Shows sanitized `ews_username` before hitting Exchange.
