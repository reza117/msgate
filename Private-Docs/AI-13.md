# AI-13 — Install / uninstall & site-agnostic release

> Status: **complete** (v0.0.9)  
> Product: **msgate**

---

## Summary

Production packaging includes **install** and **uninstall** scripts. Ship and docs use **placeholder** Exchange hosts only (`mail.example.com`). Operators learn how to build the real EWS URL; no customer site hostnames or credentials are hardcoded.

---

## User guide

### Install

```bash
sudo ./install.sh
# enables, starts, and checks http://127.0.0.1:8080/healthz
```

1. Open `http://<host>:8080/`
2. Set admin password
3. **Settings** → fill Exchange (EWS URL, username, password, primary SMTP)
4. Point Zabbix (or other) SMTP at msgate; **Email from** must match primary SMTP / Send As rights

Data directory defaults to `/var/lib/msgate` (override with `MSGATE_DATA_DIR`).

`install.sh` writes the systemd unit without embedding API bind in `Environment=` (that would override `msgate.env`). Bind via `MSGATE_API_HOST` / `MSGATE_API_PORT` in `msgate.env` only. On finish it **unmasks, enables, starts** the service and verifies `/healthz`.


### Uninstall

| Command | Effect |
| --- | --- |
| `sudo /opt/msgate/uninstall.sh` | Stop + disable service, remove unit; keep code and data |
| `sudo /opt/msgate/uninstall.sh --purge` | Also delete `/opt/msgate`, `/var/lib/msgate`, and the `msgate` system user |

**Not yet:** `sudo apt remove msgate` — that needs a published `.deb`. Use `uninstall.sh` instead.

### Single instance

`install.sh` manages **one** systemd unit at `/opt/msgate` (override with `MSGATE_INSTALL_DIR`). A second prefix is refused unless `--force`. Each run recreates `.venv` so versions do not mix.

### How to get the EWS URL

Pattern:

```text
https://<your-exchange-host>/EWS/Exchange.asmx
```

- `<your-exchange-host>` is usually the same host as Outlook Web Access (OWA) or Exchange Client Access.
- Ask your Exchange administrator for the **EWS endpoint** if unsure.
- Reachability check: `curl -k -I "https://<host>/EWS/Exchange.asmx"` (expect HTTP, not DNS/connection failure).

The Settings page and `msgate.env.example` include the same guidance.

## Technical reference

| Piece | Role |
| --- | --- |
| `install.sh` | venv, pip install, systemd unit, `MSGATE_DATA_DIR` |
| `uninstall.sh` | stop/disable/remove unit; `--purge` wipes install + data + user |
| `msgate.env.example` | LAN UI defaults; commented EWS seed + URL how-to |
| Settings UI | EWS URL help blurb |
| `EWSConfig.server_url` | OpenAPI description with URL pattern |
| `MSGATE_DATA_DIR` | Writable root (`paths.py`) — DB/logs/secrets/TLS cache. Alembic URL is overridden at runtime to this path (not hardcoded `./data`). |

**No site-specific hosts** in release artifacts, OpenAPI examples, or AI docs (use `example.com` / `DOMAIN\svc.msgate`).
