### API endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/healthz` | Liveness (SMTP up) |
| GET | `/readyz` | Readiness (SMTP + EWS + queue depth) |
| GET/PUT | `/api/v1/config` | Read/update config (secrets redacted on GET) |
| GET | `/api/v1/queue` | List queued/sent/failed messages |
| POST | `/api/v1/messages/test` | Send test email via API |
| GET | `/docs` | OpenAPI Swagger UI |

### Queue behavior

1. SMTP `DATA` → message stored in SQLite → immediate EWS attempt  
2. Success → `sent`  
3. Retriable error (429/503/timeout) → `retrying` with exponential backoff (5s → 300s cap)  
4. Max 8 attempts → `failed`  
5. SMTP always returns **250** when accepted to queue (Zabbix-friendly)

## GitHub Pages — User manual

### Start (SMTP + API + worker)

```bash
msgate serve --log-level INFO
# SMTP: 127.0.0.1:1025
# API:  127.0.0.1:8080/docs
```

### Optional env

| Variable | Purpose |
| --- | --- |
| `MSGATE_SECRET_KEY` | Encryption key (or auto-generated in `data/.secret_key`) |
| `--api-host` / `--api-port` | API bind (default `127.0.0.1:8080`) |

### Check queue

```bash
curl -s http://127.0.0.1:8080/api/v1/queue | jq
curl -s http://127.0.0.1:8080/readyz | jq
```

### Update config without restart

```bash
curl -s http://127.0.0.1:8080/api/v1/config > cfg.json
# edit cfg.json (password stays "***" to keep existing secret)
curl -X PUT http://127.0.0.1:8080/api/v1/config -H 'Content-Type: application/json' -d @cfg.json
```

SMTP bind/port changes require restart; EWS/TLS/allowlist apply immediately.
