# AI-19 — msgate-update.sh (CLI upgrade helper)

> Status: **complete**  
> Product: **msgate**

---

## Summary

**`msgate-update.sh`** upgrades in place **without wiping DB / `msgate.env`**.

Default: **`--latest`** — query GitHub Releases API, download the newest `msgate-*.tar.gz` asset, run `install.sh`.

---

## User guide

```bash
sudo /opt/msgate/msgate-update.sh              # latest from GitHub
sudo /opt/msgate/msgate-update.sh --latest    # same
sudo /opt/msgate/msgate-update.sh --local     # this tree only (no download)
```

| Env | Meaning |
| --- | --- |
| `MSGATE_GITHUB_REPO` | `owner/repo` (default `msgate/msgate`) |
| `MSGATE_GITHUB_TOKEN` | optional API token |
| `MSGATE_INSTALL_DIR` / `MSGATE_DATA_DIR` | paths |

**Release requirement:** attach a `msgate-VERSION.tar.gz` asset (GitHub “Source code” alone is not enough).

---

## Technical

Preserved: data dir + `msgate.env`. Replaced: install tree + `.venv` via `install.sh`.
