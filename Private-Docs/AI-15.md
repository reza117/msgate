## Summary

Operators can search on-disk msgate logs from the Web UI (**Logs**). Public GitHub Pages under `docs/` cover install, queue/blast knobs, capacity alerts, database choice, and the Logs UI.

---

## User guide — Logs UI

1. Sign in → sidebar **Logs**.
2. Filter by search text, level, logger substring, day (`YYYYMMDD`), and row limit.
3. Results are newest-first from `msgate-YYYYMMDD.log` under `MSGATE_LOG_DIR` or `{MSGATE_DATA_DIR}/logs`.

Requires file logging (default on). Retention: `MSGATE_LOG_RETENTION_DAYS` (default 14).
