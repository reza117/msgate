# AI-09 — Phase 4 Plan (Mail Driver Framework)

> Status: **complete** (v0.0.5)  
> Product: **msgate**  
> Graph / Gmail: **deferred** as Phase 4b / 4c after this framework ships

---

## Decision

Hold dedicated Microsoft Graph / M365 work. Prioritize a **pluggable mail driver** so future providers (Graph, Gmail, …) plug in without rewriting SMTP, queue, or UI.

**Today:** Legacy on-prem Exchange works via EWS (Phase 1–3.5).  
**Next:** Extract EWS behind `MailDriver`; keep behavior identical.

---

## Architecture

```
SMTP client → msgate SMTP → queue → MailDriver.send(mime)
                                      ├─ ews      (current)
                                      ├─ graph    (Phase 4b)
                                      ├─ gmail    (Phase 4c)
                                      └─ …
```

| Contract method | Purpose |
| --- | --- |
| `send(mime, …) → SendResult` | Deliver message |
| `health() → ok/detail` | UI badge + `/readyz` inputs |
| `config_schema` / settings | Per-driver config in API/UI |

Config example:

```yaml
backend: ews   # ews | graph | gmail | …
ews:
  server_url: …
  …
```
