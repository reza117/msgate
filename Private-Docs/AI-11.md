## User guide

### Prometheus metrics

```bash
curl http://127.0.0.1:8080/metrics
```

Public endpoint (no login). Key metrics:

| Metric | Meaning |
| --- | --- |
| `msgate_messages_sent_total` | Delivered messages |
| `msgate_messages_failed_total` | Permanent failures |
| `msgate_queue_pending` | Queue depth |
| `msgate_backend_up` | Mail driver health |
| `msgate_uptime_seconds` | Process uptime |

### Webhooks

```bash
export MSGATE_WEBHOOK_URLS="https://hooks.slack.com/...,https://discord.com/api/webhooks/..."
```

Fires JSON POST on queue events (`queue.sent`, `queue.failed`, `queue.retry`) and health checks.

### Log retention

| Env var | Default |
| --- | --- |
| `MSGATE_LOG_DIR` | `data/logs` |
| `MSGATE_LOG_RETENTION_DAYS` | `14` |
| `MSGATE_FILE_LOGGING` | `true` |

Daily log files `msgate-YYYYMMDD.log`; old files purged on `msgate serve` start.

### Config backup / restore

```bash
# Export (authenticated API)
curl -b cookies.txt -X POST http://127.0.0.1:8080/api/v1/config/export

# Import
curl -b cookies.txt -X POST http://127.0.0.1:8080/api/v1/config/import \
  -H 'Content-Type: application/json' \
  -d '{"bundle":"<encrypted>"}'
```

Bundle is AES-encrypted with `MSGATE_SECRET_KEY`.

### HA status

```bash
curl -b cookies.txt http://127.0.0.1:8080/api/v1/ha/status
```

| Env var | Example |
| --- | --- |
| `MSGATE_NODE_ID` | `node-1` |
| `MSGATE_HA_ROLE` | `active` / `passive` / `standalone` |
| `MSGATE_VRRP_STATE` | `MASTER` / `BACKUP` |
| `MSGATE_HA_LEADER` | `node-1` |

#### Keepalived (two-node sketch)

Run msgate on both nodes; only the MASTER binds SMTP/API to the VIP.

1. Install Keepalived on both VMs.
2. Active node: `MSGATE_HA_ROLE=active`, `MSGATE_VRRP_STATE=MASTER`.
3. Passive node: `MSGATE_HA_ROLE=passive`, stop `msgate` or bind localhost only.
4. Monitor: `GET /api/v1/ha/status` + `/readyz`.

Full VRRP config is site-specific — validate failover on your network before production.

### EWS failover

```bash
export MSGATE_EWS_FAILOVER_URL=https://exchange2.example.com/EWS/Exchange.asmx
# Optional: MSGATE_EWS_FAILOVER_USERNAME, MSGATE_EWS_FAILOVER_PASSWORD, ...
```

Primary send failure automatically retries via secondary Exchange.

## Install paths

### Docker

```bash
cd msgate
docker compose -f docker/docker-compose.yml up -d --build
```

Image: multi-arch build via `.github/workflows/docker.yml` (`linux/amd64`, `linux/arm64`).

### systemd

```bash
sudo ./install.sh
sudo cp msgate.env.example /opt/msgate/msgate.env
# edit msgate.env
sudo systemctl start msgate
```

### PyInstaller (optional)

```bash
./scripts/build-binary.sh
# output: dist/msgate
```
