# AI-16 — Admin digest reports (P5.5-11)

> Status: **complete** (Phase 5.5 item 11)  
> Product: **msgate**

---

## Summary

Operators can enable **daily** and/or **weekly** digest emails from **Account**. Each digest attaches a **PDF** with sent/failed counts, max delivery delay, and top errors. Optional short text body. Manual **Send digest now** available.

---

## User guide

1. **Account** → set **Admin alert email** (shared with capacity alerts).
2. Under **Digest reports**, enable daily and/or weekly, set subject / hour / weekday → Save.
3. Optional: **Send digest now** (last 24 hours).
4. Requires Exchange (EWS) configured so msgate can send mail.

Subject placeholders: `{period}`, `{from}`, `{to}`.
