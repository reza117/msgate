## GitHub Pages — Marketing blurb (draft)

**msgate** is a lightweight SMTP gateway for Microsoft Exchange and Microsoft 365.

Legacy apps, monitoring tools (Zabbix), printers, and scanners still speak SMTP. Microsoft pushed Exchange Online to OAuth2 / Graph. **msgate** sits in between: accept standard SMTP, deliver via EWS (on-prem) or Microsoft Graph (cloud).

**Tagline:** SMTP for the OAuth era.

## GitHub Pages — User manual (Phase 0)

### Requirements

- Python 3.11+ (dev) or Docker
- No Exchange connection required for Phase 0 scaffold

### Install (dev)

```bash
cd msgate
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
pytest -q
msgate
```

### Database migrate

```bash
mkdir -p data
alembic upgrade head
```

### Docker

```bash
docker compose -f docker/docker-compose.yml build
docker compose -f docker/docker-compose.yml up
```

SMTP port **1025** and UI/API port **8080** are reserved; Phase 0 container only runs the CLI stub.
