# AI-12 — Settings Web UI & Account

> Status: **complete** (v0.0.8)  
> Product: **msgate**

---

## Summary

Operators can view and change gateway configuration from the Web UI (**Settings**), without shell env vars after the first bootstrap.

Config is still loaded from env on first start, then stored encrypted in SQLite. The Settings page uses `GET/PUT /api/v1/config` (session auth).

**v0.0.8 additions:** Settings fields are **locked** until Edit; collapsible sidebar for mobile; minimal **Account** page to change the admin password.

---

## User guide

### Settings

1. Open http://127.0.0.1:8080/ui/settings (login required).
2. Fields are read-only until you click **Edit**.
3. Change values, then **Save** (or **Cancel** to discard). Required fields are marked `*`.
4. Leave **Password** blank to keep the current secret.
5. Empty optional emails (default sender) are stored as unset — they no longer block Save.

| Change | When it applies |
| --- | --- |
| EWS URL, credentials, TLS flags, primary SMTP | Immediately (hot-reload) |
| Allowed SMTP client IPs | Immediately |
| SMTP bind address / port | After `msgate` restart |

Graph / Gmail backends remain stubs — select EWS for real delivery.

### API Docs (`/docs`)

Swagger examples are **fictional** (`example.com`, `DOMAIN\svc.msgate`). They are not your live Exchange account.

**Try it out** (when logged in) returns real data from this msgate instance.

### Account

1. Open **Account** in the sidebar (or `/ui/account`).
2. Enter current password + new password (min 8 chars).
3. Forced change after env bootstrap still uses `/ui/change-password`.

### Mobile nav

On small screens use the **☰** header button to open/close the sidebar.

## Marketing / positioning

- **No CLI for day-to-day config** — set Exchange URL and credentials in the browser.
- **Safer defaults** — settings stay locked until Edit; secrets never re-display.
- **Same API as automation** — UI and `PUT /api/v1/config` share one store.

---

## Technical reference

| Piece | Role |
| --- | --- |
| `GET /ui/settings` | Locked form + Edit/Save/Cancel (Alpine) |
| `PUT /api/v1/config` | Validates, merges secrets (`***` keeps old password), persists |
| `GET /ui/account` | Minimal admin password change |
| `POST /ui/auth/change-password` | Shared by Account + forced change flow |
| Sidebar | Collapsible overlay on `< md` |

**Files:** `ui/templates/settings.html`, `account.html`, `base.html`, `api/routes/ui.py`, `api/routes/auth_ui.py`, `tests/test_settings_ui.py`.
